# Getting Started

Short vault entry. Full docs: [[README.en]] · 中文：[[如何開始使用]]

---

## Do these three things today

1. Obsidian → **Open folder as vault** on this folder’s root.
2. Confirm **Templates** folder is `7-Templates`, **Daily notes** new-file folder is `6-DailyNotes`.
3. Open today’s Daily (or insert [[DailyNoteTemplate]]) and write the one thing you most want to move.

---

## Where does this go?

| Situation | Put it here |
|-----------|-------------|
| Capture first, decide later | `0-Inbox` ([[InboxTemplate]]) |
| Has a goal and can finish | `1-Projects` ([[ProjectTemplate]]) |
| Ongoing, no single deadline | `2-Areas` ([[AreaTemplate]]) |
| Reference or reading notes | `3-Resources` ([[ResourceTemplate]]) |
| Done or no longer in focus | `4-Archives` |
| One idea, in your own words | `5-Zettelkasten` ([[ZettelkastenTemplate]]) |
| What happened today | `6-DailyNotes/YYYY-MM-DD.md` |

Unsure → `0-Inbox`. Clear it weekly with [[WeeklyInboxRitual]].

---

## Writing notes in Cursor

This vault already has Cursor rules (`AGENTS.md` + `.cursor/rules`). Open the **same root** in Cursor. Write in English (or Traditional Chinese); the agent should match your language, use `[[wikilinks]]`, and file notes in the right PARA folder.

> [!tip] Don’t rush filing
> Write and link first. Folders are temporary; `[[wikilinks]]` are the long-term index.
