# Obsidian embeds

Prefix a wikilink with `!` to **embed** content in Reading view.

## Notes and sections

```markdown
![[Note]]
![[Note#Heading]]
![[Note#^block-id]]
```

## Images

```markdown
![[photo.png]]
![[photo.png|300]]
![[photo.png|300x200]]
```

## PDF

```markdown
![[file.pdf]]
![[file.pdf#page=3]]
![[file.pdf#height=400]]
```

## Audio / video

```markdown
![[recording.mp3]]
![[clip.mp4]]
```

## Transclusions from other formats

Obsidian can embed some attachment types depending on version and community plugins; verify in-app for CSV, etc.

## External images (Markdown)

Standard syntax still works:

```markdown
![](https://example.com/image.png)
```
